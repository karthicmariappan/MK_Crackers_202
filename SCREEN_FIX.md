# MK Crackers Screen Fix

The previous catalogue used fixed pixel column widths, which caused the right-side Price/Total columns to go outside the screen at some browser zoom levels.

This version changes the price-list table to responsive percentage columns:
Image 10% | Product 24% | Content 15% | Actual 14% | Price 10% | Quantity 17% | Total 10%

The table now fits the desktop viewport without requiring browser zoom-out. It also adapts for smaller screens.

Upload the complete `public/` folder, not individual files.

If GitHub Pages still appears zoomed, reset browser zoom with Ctrl+0 once; the website itself now uses normal 100% sizing.
